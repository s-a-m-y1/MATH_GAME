# Math Game 🎮

A simple console-based Math Game written in C++.  
Test your math skills with addition, subtraction, multiplication, and division questions!  

## Features ✅
- Randomly generated math questions
- User-friendly console interface
- Tracks correct and wrong answers
- Supports multiple levels of difficulty
